# BigBasket Product Analysis – Excel

## Project Overview
This project explores the BigBasket product catalogue using Microsoft Excel. The objective is to analyse product pricing, discount patterns, category-level performance, ratings and relative pricing segments.

## Dataset
The dataset contains approximately 27,555 product records with information such as:
- Product name
- Category and subcategory
- Brand
- Sale price and market price
- Product rating

## Tools & Excel Skills
- Data cleaning and preparation
- Excel Tables and structured references
- IF, IFERROR, AVERAGEIF and COUNTIF
- XLOOKUP and FILTER
- Conditional formatting
- Pivot Tables
- Charts and data visualisation
- Dynamic product lookup
- Dashboard creation

## Key Analysis
- Product distribution across categories
- Average selling price by category
- Discount distribution
- Missing product ratings
- Relative pricing segment analysis
- Dynamic product search and lookup

## Key Findings
- Approximately 31.31% of products have missing ratings.
- Around 44.73% of products have no discount.
- Kitchen, Garden & Pets has the highest average discount among categories.
- Baby Care has the highest average selling price.
- Approximately 63.26% of products fall within the defined relative pricing range.

*Relative pricing segments are based on comparisons with subcategory average prices and should not be interpreted as definitive measures of product value.*

## Files
- `BigBasket_Analysis.xlsx` – Completed Excel analysis workbook, including data preparation, Pivot Tables, analysis sheets, lookup functionality and dashboard.

## Project Purpose
This project was created to develop practical Excel skills for data analysis, particularly in retail and FMCG analytics.
